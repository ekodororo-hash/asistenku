API key Gemini

Maksimal 5. Dicoba berurutan; kalau kena limit otomatis lompat ke key berikutnya.

Catatan privasi: pada key tier gratis, Google dapat memakai isi chat untuk meningkatkan modelnya. Jangan masukkan data sensitif milik orang lain.

Cara mendapat API key Gemini (gratis)
  1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
  2. Klik Create API key, lalu pilih atau buat project.
  3. Salin key-nya (key baru diawali AQ., key lama AIza), tempel di kolom di bawah, klik Tambah.
  • Kuota gratis per key terbatas. Tambah key dari akun Google lain (maks. 5) supaya tidak cepat habis.
  • Error 429 artinya kuota sedang penuh. Tunggu sebentar, asisten otomatis pindah ke key berikutnya.
  • Batas Google berlaku per project, bukan per key. Dua key dari project yang sama berbagi kuota yang sama, jadi buat key di project atau akun Google yang berbeda.
  • Hitungan "× hari ini" mengikuti hari kuota Google: reset tengah malam waktu Pasifik, sekitar pukul 14.00 WIB. Angka "dari ±N" di sebelahnya adalah batas gratis model utama; hitungannya perkiraan karena mencakup semua model, termasuk cadangan.
  • Jangan bagikan key ke siapa pun, termasuk lewat screenshot.

Kosongkan untuk memakai bawaan server (). Model cadangan dipakai otomatis kalau model utama kena limit di semua key atau tidak ditemukan. Klik kolom untuk memilih dari daftar; model gambar/suara disembunyikan tapi tetap bisa diketik.

Saran: utama Flash-Lite, cadangan Flash. Angka kuota dari AI Studio (Okt 2026), bisa berubah atau berbeda per project.
